# PreviewImages

Esta carpeta es el punto único para los previews de la app.

Para cada opción usa el mismo nombre base que aparece en la UI:
- preview-01
- preview-02
- preview-03
- preview-04
- preview-05
- preview-06
- preview-07
- preview-08

Formatos soportados:
- imágenes: JPG, JPEG, PNG, WEBP
- animaciones: GIF
- vídeo: MP4, MOV, M4V

Ejemplo de archivo: PreviewImages/preview-01.jpg

La pestaña Preview muestra un botón VER PREVIEW y carga automáticamente el primer archivo compatible que encuentre. No necesitas modificar SwiftUI al cambiar una imagen, GIF o vídeo; solo reemplaza/sube el archivo en esta carpeta y vuelve a compilar la IPA.
